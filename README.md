# Rxy Store

ร้านค้าในเกมสำหรับเซิร์ฟ FiveM ผู้เล่นจ่ายเงินจริงผ่าน PromptPay แล้วได้ของในเกม แอดมินตั้งค่าสินค้าได้จากในเกม

ยังทำไม่เสร็จ ตอนนี้ยังเอาไปใช้จริงไม่ได้

## ตอนนี้ทำอะไรได้แล้ว

- กด F5 หรือพิมพ์ `/shop` เพื่อเปิดหน้าร้าน
- หน้าร้านมีหมวด แบนเนอร์ ค้นหาสินค้า และใส่ตะกร้าได้ (ตอนนี้ยังเป็นข้อมูลตัวอย่าง ยังไม่ได้ต่อกับ server)
- กดสินค้าเพื่อดูรายละเอียด ของที่จะได้ ลิมิตต่อคน และเลือกจำนวนก่อนใส่ตะกร้า
- หน้าตะกร้า เปลี่ยนจำนวน เอาของออก ใส่โค้ดส่วนลด และซื้อให้คนอื่นโดยใส่ ID ผู้เล่น
- หน้าจ่ายเงิน QR PromptPay นับถอยหลัง QR หมดเวลาแล้วสร้างใหม่ได้ และหน้าจ่ายสำเร็จพร้อมใบเสร็จ
- ประวัติการซื้อ ค้นหาได้ กดเลขคำสั่งซื้อเพื่อคัดลอก จ่ายต่อได้ถ้ายังไม่จ่าย และหน้าของที่มีวันหมดพร้อมปุ่มต่ออายุ
- กล่องรับของ เก็บของที่ส่งไม่ได้กับของขวัญจากคนอื่น กดรับทีละชิ้นหรือรับทั้งหมด
- ถ้าจ่ายเงินตอนปิดร้านอยู่ จะมีแจ้งเตือนมุมขวาบนของจอว่าได้อะไรบ้าง
- หน้าแอดมิน (`/shopadmin`) จัดการสินค้า เพิ่ม แก้ ลบ เปิดปิดการขาย ลากเรียงลำดับ (ตอนนี้ยังไม่เช็คสิทธิ์ ใครก็เปิดได้)
- กด Esc หรือปุ่ม X เพื่อปิด
- เปลี่ยนสีร้านได้ใน config.lua
- เช็คเวอร์ชันใหม่จาก GitHub แล้วแจ้งใน console
- สคริปต์อื่นสั่งเปิดปิดร้านได้ผ่าน export

```lua
exports.Rxy_Store:open()
exports.Rxy_Store:close()
```

## ติดตั้ง

1. เอาโฟลเดอร์ `Rxy_Store` ไปไว้ใน `resources`
2. build หน้า web ก่อน (ดูหัวข้อถัดไป) ถ้าไม่มีโฟลเดอร์ `web/dist` ร้านจะเปิดไม่ขึ้น
3. เพิ่มใน `server.cfg`

```
ensure Rxy_Store
```

## build หน้า web

ต้องมี Node.js 18 ขึ้นไป

```
cd web
npm install
npm run build
```

ไฟล์ที่ได้จะอยู่ใน `web/dist`

ถ้าจะแก้หน้าตาร้าน ใช้ `npm run dev` แล้วเปิด http://localhost:3000 ใน browser ได้เลย ไม่ต้องเข้าเกม ถ้าจะดูหน้าแอดมินให้เปิด http://localhost:3000/#admin

## ตั้งค่า

แก้ใน `config.lua`

| ค่า | ใช้ทำอะไร | ค่าเริ่มต้น |
|---|---|---|
| `Config.OpenKey` | ปุ่มเปิดร้าน | `F5` |
| `Config.Command` | คำสั่งเปิดร้าน | `shop` |
| `Config.AdminCommand` | คำสั่งเปิดหน้าแอดมิน | `shopadmin` |
| `Config.UpdateCheck` | เช็คเวอร์ชันใหม่ตอนเปิดเซิร์ฟกับทุก 6 ชั่วโมง ปิดแล้วยังเตือนอยู่ถ้าเป็นอัปเดตที่แก้ช่องโหว่ | `true` |
| `Config.Theme.primary` | สีหลัก ใช้กับราคา ป้ายลดราคา ตัวเลขบนตะกร้า | `#FF7A1A` |
| `Config.Theme.secondary` | สีรอง ใช้กับสถานะ ส่วนลด กล่องรับของ ถ้าเป็น `nil` จะใช้สีตรงข้ามของสีหลักให้เอง | `nil` |

สีต้องเป็นรูปแบบ `#RRGGBB` ถ้าใส่ผิด ร้านจะกลับไปใช้สีเริ่มต้น

ผู้เล่นเปลี่ยนปุ่มเองได้ที่ Settings > Key Bindings > FiveM

## อัปเดต

ร้านจะบอกใน console เองถ้ามีเวอร์ชันใหม่ ถ้าอยากเช็คเดี๋ยวนั้นให้พิมพ์ใน console ของเซิร์ฟ

```
rxystore_version
```

ถ้าขึ้นสีแดงว่ามีอัปเดตที่แก้ช่องโหว่ ควรอัปเดตให้เร็วที่สุด

## โครงสร้างไฟล์

```
Rxy_Store/
├── fxmanifest.lua
├── config.lua
├── client/
│   └── main.lua        เปิดปิดหน้าร้าน
├── server/
│   └── version.lua     เช็คเวอร์ชันใหม่
└── web/                หน้าร้าน (React + Vite + TypeScript)
    └── src/
        ├── App.tsx
        ├── types.ts              รูปแบบข้อมูลสินค้า หมวด แบนเนอร์
        ├── pages/                หน้าต่างๆ ของร้าน
        ├── components/           ปุ่ม การ์ดสินค้า ช่องค้นหา ที่ใช้ทั้งร้าน
        ├── mock/                 ข้อมูลตัวอย่างไว้เทสใน browser
        ├── styles/               ฟอนต์ สี และ CSS กลาง
        ├── lib/
        │   ├── nui.ts            ส่งข้อมูลจากหน้า web ไปฝั่ง Lua
        │   ├── theme.ts          ตั้งสีร้าน
        │   └── csp.ts            กันสคริปต์แปลกปลอมตอนรันในเกม
        └── hooks/useNuiEvent.ts  รับข้อมูลจากฝั่ง Lua
```

ฟอนต์ (IBM Plex Sans Thai, IBM Plex Mono) ฝังมากับตัวร้าน ไม่ได้โหลดจากเน็ต
